## Технический контекст MLMS

### Из диплома (верифицировано):
```
Стек: Python 3.11, FastAPI, asyncpg, redis-py, pgvector-python, TimescaleDB, Alembic
БД: PostgreSQL 16 + pgvector 0.8.2 + TimescaleDB
Кэш: Redis 7
Транспорт MCP: stdio (локальный subprocess) ИЛИ SSE (HTTP, порт ~8000)
Эмбеддинги: Qwen3-Embedding-8B, output_dimension=1536, через SiliconFlow API
Индекс: HNSW, m=16, ef_construction=64, vector_cosine_ops
Таблицы: facts, session_log (TimescaleDB hypertable), timeline_events (TimescaleDB hypertable), skills, + alembic_version
```

### Метрики из диплома (возможно неточны — перепроверить):
```
Recall@5: > 80% (на синтетическом датасете 100 сценариев)
p99 latency cached path: < 200 мс
Unit tests: 28/28 — НО eB говорит тестов больше. ПРОВЕРИТЬ!
  test_smoke.py: 9 тестов (по одному на каждый MCP-инструмент)
  test_amend.py: 5 тестов (логика конфликтов и версионирования)
  test_liminal.py: 3 теста (граничные сценарии)
  Итого по диплому: 28 — но могут быть ещё файлы
```

### Что нужно сделать в директории:
```bash
# 1. Реальный счётчик тестов
pytest --collect-only -q | tail -5

# 2. Проверить транспорт — как запускается SSE-сервер
grep -r "sse\|SSE\|uvicorn\|port" . --include="*.py" | head -20

# 3. Найти docker-compose.yml — узнать порты
cat docker-compose.yml | grep -A3 "mcp-server\|ports:"

# 4. Проверить структуру тестов
find . -name "test_*.py" | xargs wc -l
```

## Демо — решение (Cherry Studio, не Claude Desktop)

**Почему не Claude Desktop:** у eB нет пустого аккаунта, и в основном могут быть нежелательные memories.

**Решение: Cherry Studio** — десктопный AI-клиент с нативной поддержкой MCP.

### Установка:
- Скачать: https://cherry-ai.com → Download → Windows EXE
- Не требует аккаунта — работает через API-ключ напрямую

### Настройка MCP в Cherry Studio:
```
Settings → MCP Servers → Add Server
  Name: MLMS
  Type: SSE (если сервер HTTP) ИЛИ stdio (если subprocess)
  URL: http://localhost:8000/sse   ← уточнить реальный порт!
  
  ИЛИ для stdio:
  Command: python
  Args: -m mlms.server   ← уточнить реальную команду запуска
```

### В чате Cherry Studio:
- Включить MLMS в списке MCP-серверов (тоггл)
- В поле чата — иконка 🔧 показывает доступные инструменты
- Выбрать API: Anthropic (claude-sonnet-4-6) или любой с tool calling

### Сценарий демо-видео (3 мин):
```
Сцена 1 [30 сек]: Терминал → docker compose up → все сервисы green
Сцена 2 [40 сек]: Cherry Studio → новый чат → MLMS инструменты видны (🔧)
  Сообщение: "Запомни: я работаю над проектом MLMS — система памяти для AI.
  Стек: Python, FastAPI, PostgreSQL+pgvector, TimescaleDB, Redis.
  Тестирование завершено — все тесты пройдены, Recall@5 = 83%."
  → Cherry Studio вызывает mlms:memorize → видно в UI
  
Сцена 3 [50 сек]: НОВЫЙ ЧАТ (!!!) → чистая история
  Сообщение: "Расскажи о проекте, над которым я работаю."
  → mlms:get_facts → AI рассказывает об MLMS из памяти!
  [ПАУЗА — дать зрителю осознать]
  
  Сообщение: "Что происходило с проектом в мае 2026?"
  → mlms:get_timeline → событие тестирования
  
Сцена 4 [20 сек]: Терминал → pytest -v → X passed (актуальное число!)
```
