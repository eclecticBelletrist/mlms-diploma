# ПРЕЗЕНТАЦИЯ MLMS — Спецификации слайдов для Figma
## 13 слайдов | Формат: 1920×1080px (16:9) | Академический стиль

---

## Общий стиль (применить ко всем слайдам)

```
Фон: тёмно-синий градиент (#0A1628 → #0D2147) или белый (#FFFFFF) с синими акцентами
Заголовки: Inter Bold или Montserrat Bold, 48-56pt
Тело: Inter Regular, 24-28pt
Акцент/числа: цвет #4A90E2 (синий) или #2ECC71 (зелёный для результатов)
Логотип/марка: аббревиатура "MLMS" в правом нижнем углу + номер слайда
Поля: 80px со всех сторон
ЗАПРЕТ: не больше 6 строк текста на слайде. Тезисы, не абзацы.
```

## СЛАЙД 8 — Архитектура системы

**Заголовок:** "Архитектура MLMS"

**Схема (горизонтальная, слева→направо):**

```
[LLM-клиент]
    ↓ MCP JSON-RPC
[MCP-сервер (FastAPI/Python)]
    ↓ Storage Layer
┌─────────┬──────────────┬──────────────┬──────────┐
│  Redis  │  TimescaleDB │  PostgreSQL  │   SQL    │
│         │              │  + pgvector  │  skills  │
│Рабочая  │ Эпизодичес.  │ Семантичес.  │Процедур. │
│  память │    память    │    память    │  память  │
└─────────┴──────────────┴──────────────┴──────────┘
```

**Справа от схемы — мини-легенда:**
```
🔵 <5 мс доступ (Redis)
🟡 Темпоральные запросы
🟢 Косинусный поиск (HNSW)
🟣 Версионирование
```

**Стиль:** схема как блок-диаграмма с цветами по типу памяти, стрелки тонкие
